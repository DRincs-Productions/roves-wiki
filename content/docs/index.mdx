**Roves** is a customized, vendored fork of [Servo](https://servo.org) — a modern web
engine built from scratch, not a repurposed browser — used as a native runtime for
shipping web-built games as real desktop apps instead of a browser tab.

You build your entire game however you already do (React, Vue, Vite.js, plain
HTML/CSS/JS — anything that runs in a browser). Roves takes that built output and
produces a single, double-click-runnable binary for Windows, macOS, and Linux — with your
content either sitting next to it or packed straight into the bundle.

## How it fits together

Roves is one of two distribution targets a game built on the
[pixi-vn-react-template](https://github.com/DRincs-Productions/pixi-vn-react-template) project
can target — the other being [Tauri](https://tauri.app/). Both wrap the same web content;
they differ in what actually renders it. See <DynamicLink href="/docs/why">Why Roves?</DynamicLink>
for the full comparison.

Roves itself is not a from-scratch engine — it is upstream [Servo](https://servo.org),
vendored and patched (not forked on GitHub — see the project's `CLAUDE.md`) with a
focused, documented set of changes: no browser chrome (toolbar, tabs, address bar), a
branded boot splash, single-executable bundling, packed-content extraction, a Steam
bridge, and a few other game-shell-shaped conveniences. Every change is tracked in
[`CUSTOMIZATIONS.md`](https://github.com/DRincs-Productions/roves/blob/main/CUSTOMIZATIONS.md)
with the reasoning behind it, and mirrored as a real, machine-applicable patch under
[`patches/`](https://github.com/DRincs-Productions/roves/tree/main/patches) — so upgrading to
a newer Servo release means reapplying documented, reviewable diffs, not re-deriving
changes from scratch.

For anything about the engine itself that isn't specific to Roves — how rendering, layout,
or the DOM/JS implementation works — the [Servo wiki](https://servo.org) is the right place
to look; this documentation only covers what Roves changes or adds on top.
