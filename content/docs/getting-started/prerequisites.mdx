title: Prerequisites
description: What you need installed before building Roves.
---

Roves builds exactly like upstream Servo, using the same `mach` tooling — see the
[Servo wiki](https://servo.org) for the authoritative, up-to-date build documentation.
This page only calls out the parts specific to working in *this* repo.

## Rust

The exact toolchain version is pinned in `rust-toolchain.toml` at the repo root — `rustup`
picks it up automatically once you `cd` into the repo, no manual version selection needed.

## Python 3.11+

Servo's `mach` tooling (the `./mach build`/`./mach bundle` commands) needs **Python 3.11 or
newer**. A couple of Python standard-library additions used by `python/mach`/`python/tidy`
(`contextlib.chdir`, `typing.LiteralString`) simply don't exist on 3.10 — `mach` will fail
importing its own commands, not just warn, on an older interpreter.

The repo expects [`uv`](https://github.com/astral-sh/uv) to provision the right Python
version automatically; without it, `mach` falls back to whatever `python3` resolves to on
`PATH`, which is a real, easy-to-hit gap on Linux distributions that still default to 3.10.

## Platform build dependencies

Run `./mach bootstrap` first — it installs the platform-specific system packages Servo's
build needs (a C/C++ toolchain, `libclang`, and a handful of media/graphics libraries). If
you skip it and hit a `bindgen`/`libclang` error, or a linker error naming `-ludev`, that's
this step — the `gamepad` feature (on by default) links `libudev` on Linux specifically.

## Disk space and RAM

Servo bundles SpiderMonkey (the JS engine, compiled from C++) and ANGLE (GL-over-native
graphics translation). A clean build compiles a lot of C++ in addition to Rust — budget
real disk space for `target/` and enough RAM that a fully parallel build doesn't thrash;
if you're memory-constrained, `cargo build -j <n>` with a lower job count trades build time
for peak memory.
